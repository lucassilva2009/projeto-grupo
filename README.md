# FitIA

Sistema web desenvolvido para auxiliar usuários no acompanhamento de indicadores físicos, cálculo de IMC e definição de objetivos relacionados à saúde e condicionamento físico. O projeto permite a criação de perfil personalizado e a geração de recomendações com base nas informações fornecidas pelo usuário.

## Funcionalidades

- Criação de perfil físico do usuário. 
- Cálculo e classificação de IMC. 
- Painel com informações do usuário. 
- Definição de objetivos relacionados à saúde e condicionamento físico. 
- Recomendações personalizadas. 

## Tecnologias

- PHP
- JavaScript

## Como Executar

1. Instale um servidor local com suporte a PHP:
   - XAMPP (testado ok)
   - WampServer
   - Laragon

2. Clone o repositório:

```bash
git clone https://github.com/lucassilva2009/projeto-grupo.git
```

3. Copie os arquivos para o diretório do servidor web.

4. Acesse:

```text
http://localhost/projeto/FitIA.html
```
